# 🌐 Personal Portfolio Website

Welcome to the repository for my personal portfolio website! This project is a clean, minimal, and fully responsive website designed to showcase my skills, projects, and journey as a developer

## 🚀 Features

*   **About Me Section:** A brief introduction to who I am and what I do.
*   **Projects Gallery:** Visual showcase of my web development projects with source code links.
*   **Skills Grid:** A dedicated section highlighting my technical toolkit.
*   **Contact Form / Links:** Clean layout allowing visitors, recruiters, and collaborators to get in touch.
*   **Responsive Design:** Fully optimized for viewing on desktops, tablets, and mobile phones.

---

## 🛠️ Tech Stack

This project was built from scratch utilizing standard frontend practices to ensure fast load times and accessible layouts:

*   **HTML5:** Semantic structure and content layout.
*   **CSS3:** Custom layouts, responsive typography, flexbox grid design, and smooth hover effects.
